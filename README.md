# ZYQORA

**Your Sound. Your Universe.**

ZYQORA is an Android music player project with music discovery, playback, library and playlist tools, downloads, lyrics, themes, and a glass-inspired interface.

## Build a debug APK

1. Upload the contents of this project folder to your GitHub repository.
2. Open **Actions** and select **Build ZYQORA APK**.
3. Choose **Run workflow** and wait for the workflow to finish.
4. Open the successful run and download the `ZYQORA-debug-APK` artifact.

The debug APK is for testing and is not a Play Store release build. Playback and playlist features depend on their required music-service endpoints; those service URLs are intentionally retained so core functionality is not broken.
